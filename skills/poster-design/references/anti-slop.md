# What makes work look generated, and what to do instead

"Slop" is not about who or what made it. It is work where no decision was made: every choice is the first available one. The fix is never a filter or a texture. It is a decision.

## The test
For any poster, try to answer these. If you cannot, it is slop, however polished.

1. What is the idea, in one sentence?
2. Why this typeface and not the default?
3. What is the accent colour *for*?
4. Why is the biggest thing the biggest?
5. What did you take out?

## Tells and their fixes

| Tell | Why it reads as generated | Do this |
|---|---|---|
| Purple-to-blue or pink-to-orange gradient ground | The most common default there is | Flat ground in a colour taken from the subject; a gradient only where light explains it |
| Everything centred in a stack | No composition decision was made | Choose an axis or an edge; let one element break it |
| Glow, neon outline, soft drop shadow on text | Effects standing in for contrast | Raise contrast, or put the text on plain ground |
| Frosted-glass cards and rounded panels | A web interface habit | Type sits on the sheet. Use a rule or space to group, not a box |
| A row of three icons with labels | Fills space, says nothing | Cut it, or write the three facts as a tight list |
| Emoji or clip-art icons | No drawing was done | Draw one simple mark, or use none |
| One headline word in the accent colour, every time | A formula | Emphasise only if that word is the idea; change one property |
| Tiny capitals label above every block | Decoration posing as structure | One label at most, where it tells you something |
| Five sizes that are almost the same | No hierarchy | Three or four levels with big jumps |
| Three or more typefaces | Indecision | Two, or one family |
| Stock-looking generated people, extra fingers, plastic skin | Obvious, and distrusted | Supplied photographs, a drawn object, or type only |
| Garbled or nearly-right lettering inside an image | The surest sign | All text is live type, set by you, from the brief |
| Placeholder text, "your logo here", sample numbers | Nobody finished it | Real copy from the brief, or the element is removed |
| Badges, bursts, ribbons, "NEW", "50% OFF" in every corner | Everything shouts, so nothing is heard | One message. Move the rest off the poster |
| Contact strip: phone, web, three social icons | Template furniture | One way to act: a date and place, or one link or QR |
| Decorative blobs, sparkles, random circles and lines | Shapes with no job | Every shape carries, points or structures. Otherwise delete |
| Perfect symmetry and even spacing everywhere | No tension | Unequal space: tight groups, wide gaps between groups |
| Invented claims, awards, statistics, testimonials | Dishonest, and usually wrong | Only facts given by the person |
| A texture or grain laid over everything to look "designed" | A costume | Texture only when the lineage calls for it (print, riso) and you can say why |

## Habits of made work
- **It was cut.** Something that was true and available is not on the sheet.
- **One thing is extreme.** A size, a crop, an amount of empty space.
- **It belongs to its subject.** Change the name and the design stops making sense. If you could swap in a competitor's name and nobody would notice, start again.
- **Details agree.** The same margin everywhere, the same rule weight, edges that line up, one corner radius or none.
- **It was looked at.** At thumbnail size, blurred, in grey, and with the grid on.

## Before you say it is done
- [ ] I can say the idea in one sentence, and it is on the sheet.
- [ ] I removed at least one element after the first render.
- [ ] Nothing on the sheet is there because sheets like this usually have it.
- [ ] No text, number, name or logo came from me.
- [ ] `check.py` has no FAIL, and each WARN is fixed or explained.
- [ ] Swapping the name for a competitor's would break the design.
